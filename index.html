Impacto de las tecnologías web en la sociedad y los negocios

Pensemos en algo que hacemos antes de salir de casa, como buscar el horario de una tienda o averiguar qué documentos necesitamos para un trámite. Muchas veces esa consulta empieza en un navegador. La web también está presente cuando estudiamos, buscamos trabajo o queremos comparar un producto antes de comprarlo.

¿Qué son las tecnologías web?

Las tecnologías web son el conjunto de lenguajes, herramientas, protocolos y estándares que permiten crear, gestionar y visualizar páginas y aplicaciones web.
Por ejemplo, cuando abrimos una página, el navegador solicita información a un servidor. El servidor responde con los datos o archivos que el navegador necesita para mostrarla. Cuando se utiliza HTTPS, la información viaja cifrada entre el navegador y el servidor.

Categorías de las tecnologías web
Categoría Función principal Ejemplos habituales
Frontend (cliente) Construye la interfaz que vemos y usamos en el navegador. HTML, CSS, JavaScript, React, Angular y Vue.js.
Backend (servidor) Procesa solicitudes y aplica las reglas de la aplicación. Python, Node.js, PHP, Java y Ruby.
Bases de datos Guardan y organizan información para consultarla o actualizarla. MySQL, PostgreSQL, MongoDB y Redis.
Protocolos y APIs Facilitan el intercambio de información entre sistemas. HTTP, HTTPS, REST, GraphQL y WebSocket.
Servidores y nube Permiten alojar y ofrecer el sitio web a los usuarios. Apache, Nginx, AWS y Google Cloud.

La web en la vida diaria

Como estudiante a distancia, puedo entrar al EVA de la UTPL para revisar las indicaciones de una actividad, descargar una guía o entregar una tarea. También puedo volver a consultar el material si me queda alguna duda. Eso me ayuda a organizar mi tiempo de estudio durante la semana.

La web también facilita la comunicación. Por ejemplo, si tenemos que hacer un trabajo en grupo, podemos compartir un documento y revisar los aportes de cada compañero desde distintos lugares. Para hacerlo, necesitamos contar con un dispositivo y una conexión que permita acceder a esos materiales.

La web en los negocios

Un negocio pequeño puede usar un sitio web para publicar sus productos, informar sus horarios y mostrar cómo contactarlo. Pensemos en una panadería de Azogues. Si tuviera un catálogo en línea, un cliente podría revisar qué panes vende y consultar los precios antes de ir al local. Para que el catálogo sea útil, la panadería tendría que actualizarlo cuando cambien los precios o se agoten los productos.
